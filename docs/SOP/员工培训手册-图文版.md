## 第 1 章 · 订单管理

订单是系统核心：**一料号一行**（15 列 RMB 口径）。同一客户、同一 PO、不同料号 = 多行。

### 1.1 业务流转总览

```mermaid
flowchart LR
  A[订单录入] --> B[订单明细]
  B --> C{未结数量>0?}
  C -->|是| D[未结订单]
  C -->|否| E[正常结案]
  D -->|出货| F[出货明细]
  F -->|未结=0| E
  D -->|强制结案| G[强制结案]
  F --> H[应收对账]
```

| 按钮 | 适用场景 |
|------|----------|
| **订单 OCR 识别** | 客户 PO 为 PDF、扫描件、照片 |
| **手动录入** | 少量补录、无电子版 PO |

未选择前，下方只有提示「请先选择录入方式」。

### 1.3 方式 A · OCR 识别（逐步操作）

#### 适用

- 客户发来 PDF / 图片采购订单  
- 一行料号对应表格一行，识别后批量提交  

#### 操作步骤

**步骤 1** · 点 **「订单 OCR 识别」**  
**步骤 2** · 在 **「上传订单识别」** 区点 **选择文件**  
  - 支持：`.pdf`、`.png`、`.jpg` 等  
  - **可按住 Ctrl 多选** 多个文件  
**步骤 3** · 点 **「识别」**，等待进度条（多文件按顺序：OCR → AI 整理 → 规则校验）  
**步骤 4** · 识别成功后出现 **「识别预览」** 区域  

#### 预览区结构

| 区域 | 作用 |
|------|------|
| **上方 · 订单原件** | PDF 转 **200 DPI 高清图**；可 +/− 缩放、「适合宽度」、「新窗口打开」、「收起原件」 |
| **下方 · 识别表格** | 每料号一行；可直接改单元格 |
| **校验摘要** | 黄色 = 规则未通过，须核对 |

📷 **图 1-2** · 上传区  
![图1-2：OCR上传](./images/03-ocr-upload.png)

📷 **图 1-3** · 预览核对  
![图1-3：OCR预览](./images/03-ocr-preview.png)

#### 重点核对项

| 列 | 说明 |
|----|------|
| 客户 | 是否与 PO 一致；简称可能需改全称 |
| 订单号 | PO 号 |
| 品名规格 / 客户料号 | 料号须在 BOM 已建档（见第 4 章） |
| PO数量 | 须 > 0 |
| 账期 | **自由文字**，按合同填写 |
| 人民币单价（含税） | 与 PO 一致 |

**步骤 5** · 改完黄标记行  
**步骤 6** · 点 **「批量提交录入」**  
**步骤 7** · 成功后自动跳转 **订单明细**，新行 **黄色高亮约 15 秒**

⚠️ **注意**

- **黄色格子** 未改完也可能提交失败或数据不准，务必对照原件。  
- 识别成功后会 **自动归档** 原文件到 `orders/客户名/`，文件名 `接单日期_订单号.pdf`。  
- 同一 **客户 + 订单号 + 品名规格** 不能重复新建，系统会拒绝并跳到已有行。

💡 **提示**

- 多文件时，用顶部下拉切换原件。  
- 可点 **「查看 OCR 原文」** 对照机器识别字。  
- **账期** 无固定下拉，OCR 识别什么就显示什么，可手改。

🧪 **练习**

1. 用 1 份测试 PO 完成识别 → 提交 → 在订单明细找到新行。  
2. 故意留一个黄标记，观察提交时的提示。

### 1.4 方式 B · 手动录入（逐步操作）

#### 操作步骤

**步骤 1** · 点 **「手动录入」**  
**步骤 2** · 填写表单（分三组）  

**第一组 · 订单基本信息**

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 客户 | ✓ | 下拉选择；无则点 **+** 快速新增名称 |
| 接单日期 | ✓ | 本公司接单日期 |
| 客户交期 | | 客户要求交货日 |
| 订单号 | ✓ | 客户 PO 号 |
| 账期 | | 自由填写 |

**第二组 · 产品信息**

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 品名规格 | ✓ | 下拉；**+** 仅新增品名选项，不建 BOM |
| 客户料号 | | 填写后 **离开输入框**，系统查 BOM 回填品名/单重/材质 |
| 单重（g） | | 数字或文字如「外购件」 |
| 材质 | | 如 ADC12 |
| PO数量 | ✓ | 须 > 0 |

**第三组 · 数量与价格**

| 字段 | 说明 |
|------|------|
| 已出货 | 新单填 **0** |
| 单位 | 如 PCS |
| 税率(%) | 如 13 |
| 人民币单价（含税） | 含税单价 |

**步骤 3** · 点 **「提交录入」**  
**步骤 4** · 需要重填时点 **「清空」**

📷 **图 1-4**  
![图1-4：手动录入表单](./images/04-manual-form.png)

⚠️ **注意**

- 填写了 **客户料号** 时，须已在 **BOM录入** 建档且 **客户一致**，否则无法保存。  
- **未结数量** 系统自动算 = PO数量 − 已出货，**不要手填**。  
- **已出货** 不能 < 0 或 > PO数量。

🧪 **练习**：手动录入 1 条测试料号（先完成 BOM 建档）。

### 1.6 未结订单与出货

**进入路径**：**订单管理 ▾ → 未结订单**

只显示 **未结数量 > 0** 的行。

#### 交期颜色含义

| 颜色 | 含义 |
|------|------|
| **黄色背景** | 距客户交期 ≤ **10 天** |
| **红色背景** | 已过客户交期仍未结清 |
| **橙色** | 接单日期早于 **6 个月** 的老单 |

📷 **图 1-6a** · 未结列表（可选：`warn-yellow-red.png`）

#### 单次出货 — 逐步操作

**步骤 1** · 在未结列表找到料号行  
**步骤 2** · 点 **「出货」**  
**步骤 3** · 弹窗 **「出货确认 · 送货单」** 中：  
  - 核对收货地址、联系人（来自客户档案）  
  - 填写 **本次出货数量**（≤ 当前未结）  
  - 浅黄底字段可手填：批号、箱数、备注、签收等  
**步骤 4** · 点 **「确认出货并生成送货单」**  
**步骤 5** · 系统自动打开送货单，可打印或 **下载 Excel**  

📷 **图 1-6** · 未结与出货按钮  
![图1-6：未结出货](./images/06-open-ship.png)

📷 **图 1-7** · 出货确认弹窗  
![图1-7：出货确认](./images/06-ship-confirm.png)

#### 出货后会发生什么

| 变化 | 说明 |
|------|------|
| 已出货 | 增加本次数量 |
| 未结 | 自动 = PO − 已出货 |
| 未结 = 0 | 行从未结消失，进入 **正常结案** |
| 出货明细 | 新增一条出货记录 |
| 成品库存 | 自动扣减（不足则 **无法出货**） |
| 应收 | 按账期计入对应 **收款月** |

⚠️ **注意**

- 出货数量 **不能超过未结**。  
- 成品仓不足时，须先在 **工序出入库** 补成品或检查 BOM/库存。  
- 送货单内容与确认时一致，后续可在 **出货明细** 补打。

### 1.9 正常结案 vs 强制结案

| 类型 | 进入路径 | 含义 |
|------|----------|------|
| **正常结案** | 订单管理 → 正常结案 | 未结 = 0（出完或未结为 0 的导入行） |
| **强制结案** | 订单管理 → 强制结案 | 在未结订单点 **「结案」** 强行关闭 |

⚠️ **强制结案注意**

- **不记出货**、**不生成送货单**  
- **不纳入应收对账**  
- 适用于客户取消、坏账等；须主管确认后再操作  

**步骤（强制）** · 未结订单 → 行末 **结案** → 阅读确认框 → 确定

| 规则 | 内容 |
|------|------|

## 第 2 章 · 对账（应收 / 应付）

### 2.1 应收 — 客户收款到期

**进入路径**：**对账 ▾ → 应收**

#### 页面打开后看到什么

- 自 **当月** 起连续 **6 个月** 的收款到期汇总（在列表内 **上下滚动** 浏览）  
- 每一段：**月份标题 + 各客户金额 + 段内合计**  
- 工具栏：**近 6 月合计 ¥xxx**

📷 **图 2-1**  
![图2-1：应收到期](./images/08-reconcile-outlook.png)

#### 收款月怎么来的

- 依据 **出货日期** + **全局收款账期**（默认常见：**月结 90 天 · 每月 25 日**）  
- 例：7 月出货 → 收款月可能在 **10 月**，故 7～9 月段可能显示「该月暂无到期」—— **属正常**  

💡 **提示**：财务可对照 `data/reconciliation_config.json`（由管理员维护）。

#### 查看某一客户明细

**步骤 1** · 在对应月份段找到客户行  
**步骤 2** · 点 **「查看明细」**  
**步骤 3** · 显示该客户该月所有出货对账行（订单号、料号、出货日、数量、金额等）  
**步骤 4** · 点 **「← 返回汇总」** 回到 6 月视图  

📷 **图 2-2**  
![图2-2：应收明细](./images/08-reconcile-detail.png)

#### 汇总页额外筛选（可选）

### 2.2 应付 — 外协供应商付款到期

**进入路径**：**对账 ▾ → 应付**

#### 数据来源

- **外发回货**：在 **工序出入库** 登记「回货入库」

- **结算月**：按 **供应商对账周期**（须在供应商档案维护）  
- **付款月**：按 **供应商账期**  

界面与应收对称：**6 个月滚动 + 查看明细**。

📷 **图 2-3**

#### 明细页筛选

可填 **收货起 / 收货止** 限定回货日期范围。

⚠️ **注意**

- 供应商 **账期、对账周期** 为空时，应付月可能不准。  
- 回货前须 BOM 有对应 **外发工序单价**。

🧪 **练习**：完成一次外发「发出 → 回货入库」后，在应付中找对应供应商月份。

## 第 4 章 · BOM 分析

BOM = **客户料号主数据**（模具、单重、材质、工序、成本）。**订单录入认 BOM，不认历史订单。**

### 4.1 BOM 录入

**进入路径**：**BOM分析 → BOM录入**（或 `/bom/entry`）

#### 操作步骤

**步骤 1** · 填 **客户名称**、**产品料号**（= 订单里的客户料号）  
**步骤 2** · 填产品名称、模具编号、模穴、单重、材质、机台吨位  
**步骤 3** · 在 **工序选择** 区勾选本件工艺路线，填写各工序 **单价**；外发工序选 **供应商**  
**步骤 4** · 可选 **「预览成本」** 看汇总  
**步骤 5** · **「提交保存」**  

📷 **图 4-1**  
![图4-1：BOM录入](./images/12-bom-entry.png)

⚠️ **注意**

- 同一 **产品料号** 只能绑定 **一个客户**。  
- 料号已存在时会带出部分字段，改完再保存。  
- **订单录入** 填料号后离开输入框，会自动回填品名/单重/材质。

🧪 **练习**：为新料号完整建 BOM（含至少 1 个外发工序），再回订单录入验证自动回填。

## 第 5 章 · 库存

### 5.1 库存总览

| **测 / 实** | 演示数据标 **测**，正式数据标 **实** |
| **待回货** | 在途 > 0 时工序站提示 |
| 出入库流水 | 历史变动记录 |

**步骤 1** · 可选填料号 → **查询**（留空查全部）  
**步骤 2** · 点 **「出入库登记」** 跳转登记页  

📷 **图 5-1**  
![图5-1：库存总览](./images/13-inventory-board.png)

⚠️ **注意**

- **「写入10料号演示」** 仅测试用，数据标 **测**，正式环境勿随意点。  
- **订单出货** 会自动扣成品；此处「成品出货」是 **手工扣库**（非销售出货）。

---

### 5.2 工序出入库

**进入路径**：**库存 ▾ → 工序出入库**

#### 页面分三块

1. **载入区**：输入料号 → **载入工序库存**  
2. **工序站 + 登记动作**（载入后显示）  
3. **当日出入库流水**（**打开即显示今天全部料号**，无需先载入）

📷 **图 5-2**  
![图5-2：工序出入库](./images/13-inventory-entry.png)

#### 四种动作

| 动作 | 何时用 | 库存变化（简化） |
|------|--------|------------------|
| **完工转入** | 场内工序完成 | 上道场内 ↓ → 本道场内 ↑（首道直接加场内；末道进成品） |
| **发出** | 外发 | 上道场内 ↓ → **本道在途** ↑ |
| **回货入库** | 外协送回 | **本道在途** ↓ → **本道场内** ↑ |
| **成品出货** | 非订单手工出库 | 成品库存 ↓ |

#### 典型外发流程

```
上道工序有场内货
    → 点本道「发出」（供应商、数量）
    → 等回货
    → 点本道「回货入库」
    → 若要发下一道：点下道工序「发出」
```

#### 登记步骤（通用）

**步骤 1** · 输入料号 → **载入工序库存**  
**步骤 2** · **点选** 某一工序站（高亮）  
**步骤 3** · 点动作按钮（如 **发出**）  
**步骤 4** · 看提示「从哪扣 → 到哪增」  
**步骤 5** · 填 **数量**、可选备注 → **提交登记**  
**步骤 6** · 成功提示含单号（如 `FC-20260723-001`），下方流水刷新  

#### 单号规则（自动生成）

| 前缀 | 动作 |
|------|------|
| WG | 完工转入 |
| FC | 发出 |
| RK | 回货入库 |
| CP | 成品出货 |

⚠️ **注意**

- 数量不能超过当前 **场内/在途** 余额，否则提交失败。  
- 外发 **发出** 时供应商来自 BOM；须与 **供应商档案** 一致。  
- **订单出货** 仍走未结订单，与此处 **成品出货** 不同。

🧪 **练习**

1. 打开页面 **不载入料号**，确认能看到 **当日流水**。  
2. 载入一料号：做一次 **发出 + 回货入库**，在总览看 **待回货** 变化。
