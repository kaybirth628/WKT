## 一、怎样打开系统

1. 打开文件夹 `P:\WKT`。
2. 双击 **「一键启动网页.bat」**。
3. 稍等片刻，浏览器会自动打开系统页面。  
   若未自动打开，在浏览器地址栏输入：`http://127.0.0.1:5000`
4. **登录**：首次使用默认管理员账号 **`admin`** / 密码 **`WKT@2026`**，登录后请立即修改密码。  
   管理员可在 **用户管理**（`/admin/users`）为员工创建、编辑、删除账号。
5. 启动后会出现一个黑色或蓝色的命令行窗口，**请不要关闭它**，关闭后网页将无法使用。

**需要重新进入系统时**：再次双击「一键启动网页.bat」即可，程序会自动重启服务。

## 二、界面长什么样

打开系统后，页面分为 **上、中、下** 三部分：

**顶部导航栏（一行）**

| 菜单 | 作用 |
|------|------|
| **订单管理** ▾ | 点击展开下拉：订单录入、出货明细、未结订单、正常结案、强制结案 |
| **对账** ▾ | 应收、应付 |
| **客商信息维护** ▾ | 客户信息维护、供应商信息维护 |
| **BOM信息** ▾ | BOM录入（料号主数据）、BOM查询 |
| **库存** ▾ | 库存总览、工序出入库、出入库流水 |
| **操作记录** | 查看本人操作历史（管理员可看全员） |
| **用户管理** | 仅管理员：创建/编辑/删除员工账号、重置密码、启用禁用 |
| **退出** | 右上角退出登录 |
| **AI 数据助手** | 自然语言查数 |

**中间工作区（全宽）**

- 直接显示当前功能的表格、表单或 OCR 区域，**不在顶部单独占标题栏**。
- **订单录入**：OCR 上传或手工表单；录入成功后可在「订单明细」查看。
- **订单明细 / 出货 / 未结 / 结案 / 对账**：以表格为主；点 **修改** 可在行内编辑。
- **客户信息维护**：新增客户、表格内维护档案；送货单可选「不使用 / 威可特统一模板 / 专用模板」。
- **供应商信息维护**：维护外协供应商档案，供 BOM 工序选供应商时使用。

**底部说明栏**

- 显示当前模块 **标题** 与 **一行简要说明**（切换菜单时自动更新）。

**切换功能**：点击顶部菜单；订单子功能在 **订单管理** 下拉中选择。

## 三、订单录入

订单录入支持两种方式：**识别客户订单文件（OCR）**、**手工填写**。（Excel 批量导入已暂时关闭，恢复时在 `app.js` 将 `FEATURE_EXCEL_IMPORT` 改为 `true`。）每次进入页面时，需要先选择其中一种方式。

### 3.1 先选择录入方式

进入「订单录入」后，页面上方有两个按钮：

| 按钮 | 适用场景 |
|------|----------|
| **订单 OCR 识别** | 客户发来 PDF 或图片格式的采购订单，希望系统自动识别后批量录入 |
| **手动录入** | 没有电子版订单，或只需录入少量、个别料号 |

选择前，页面只显示上述按钮和一句提示「请先选择录入方式」。  
选好之后，才会出现对应的上传区或填写表单。

---

### 3.2 方式一：识别订单文件（OCR）

适合：客户 PO 为 PDF、扫描件或照片。

**操作步骤**

1. 点击 **「订单 OCR 识别」**。
2. 在 **「上传订单识别」** 区域点击选择文件，支持 PDF 和常见图片；**可按住 Ctrl 一次选多个文件**。
3. 点击 **「识别」**，页面上会出现**进度条**（多文件时按顺序逐个识别：OCR → AI 结构化 → 规则校验）。
4. 识别完成后，预览区上方显示 **「识别校验结果」**（PDF 文字层 / RapidOCR；关键字段规则校验，异常处黄标记）。
5. 识别成功后：**上方全宽展示订单原件**（PDF 自动转为 **200 DPI 高清图**，默认原始大小显示，可 + 放大）；**下方**为识别结果表格。
6. **重点核对标记**：
   - **黄色**：未通过规则校验（如料号为空、格式异常）；
   - 点击摘要列表可定位到对应格子；
   - 原件区可用 **+ / − / 适合宽度** 调整大小，或 **新窗口打开**；核对完可 **收起原件** 专注改表格。
   - 多文件时顶部下拉切换；表格中文件名可点击定位原件。
   - 可点击 **「查看 OCR 原文」** 对照原始识别文字。
7. 逐行检查表格内容；**账期**列可按识别结果直接修改文字（与 Excel 一致，无固定选项）。
8. 核对无误后，点击 **「批量提交录入」** 保存。

**账期填写说明**

- **账期** 按实际商务条款填写，可为任意文字（如「开票当月不算，从次月起月结60天」），系统不做固定选项限制。
- OCR 识别出的账期可在预览中直接改字后再提交。

**核对小技巧**

- 多文件上传时，每行第一列会显示来源文件名。
- 无黄标记时可快速浏览后提交；有黄标记时对照**左侧原件**或 OCR 原文修改。

**订单文件自动归档**

- 识别成功后，系统会将**您上传的原始订单文件**另存一份到项目文件夹 `P:\WKT\orders\` 下。
- 按 **客户名称** 分子文件夹；文件名格式为 **`接单日期_订单号`**（保留原扩展名，如 `.pdf`）。
- 示例：`P:\WKT\orders\华东精密机械\2026-05-12_PO1B260512063.pdf`
- 同一客户、同一日期与订单号重复上传时，会自动追加序号（如 `_1`、`_2`），不会覆盖已有文件。
- 识别成功提示中会显示「已归档到 orders/」；归档失败不影响识别预览，可手动保存原文件。

---

### 3.3 方式二：Excel 批量导入（暂不可用）

> 当前版本已在界面隐藏 Excel 导入。需要恢复时，将 `test_impl/web/static/app.js` 顶部 **`FEATURE_EXCEL_IMPORT`** 改为 **`true`** 并刷新页面。

适合：所有客户订单已整理在 Excel 中，需一次性迁入系统并核对金额。

**操作步骤**

1. 点击 **「Excel 导入」**。
2. 点击 **「下载导入模板」**，按模板列名整理数据（也可使用自有 Excel，但首行表头需包含系统能识别的列名，见下表）。
3. 选择 `.xlsx` 或 `.csv` 文件，点击 **「解析并校验」**。
4. 解析完成后查看三类结果：
   - **已通过**：无错误，可先点 **「导入已通过」** 入库；
   - **待确认**：有警告但可导入，显示在 **「待确认（Excel 导入）」** 栏，核对后点 **「确认导入待确认」**；
   - **阻断**：有错误，**下方红框** 与 **「下载阻断报告」** 输出完整原因（含 Excel 行号、客户、订单号、具体错误）。
5. 建议流程：解析 → **导入已通过** → 核对 **待确认** → 改 Excel 后重新解析 **阻断** 行。

**推荐表头（与模板一致）**

客户、接单日期、客户交期、订单号、品名规格、客户料号、单重（不含损耗）g、材质、PO数量、已出货、未结数量、单位、税率、人民币单价（含税）、账期（与下载模板一致，共 15 列）。

**自动校验规则**

| 校验项 | 说明 |
|--------|------|
| 未结数量 | 若 Excel 填写了「未结数量」，须等于 **PO数量 − 已出货** |
| 金额（可选列） | 模板不含金额列；若台账另有「金额」列，须等于 **PO数量 × 人民币含税单价**（四舍五入到 2 位小数，允许 0.01 元误差） |
| 已出货 | 须在 0 ~ PO数量 之间 |
| 账期 | **按 Excel 原文导入**，不做月结30/60/90 等固定限制 |
| 必填 | 客户、订单号、品名规格、PO数量 |

- 列表中的 **未结数量** 仍由系统按 PO − 已出货 自动维护，无需在系统中单独录入。
- 每个料号占 Excel 一行，与 OCR/手工录入一致。

### 3.4 方式三：手工录入

适合：少量录入、补录、或修改已有记录。

**操作步骤**

1. 点击 **「手动录入」**。
2. 按表单 **两行** 填写（带 * 或系统提示的为必填项）：

**第 1 行（产品）**：客户 → 客户料号 → 品名规格 → 单重 → 材质  

**第 2 行（订单与价格）**：客户交期 → 订单号 → PO 数量 → 税率 → 人民币单价（含税）

| 填写项 | 说明 |
|--------|------|
| 客户 | **可搜索下拉**（§全局 UI 规则）；新客户请在 **客商信息维护** 中添加 |
| 客户料号 | 可搜索下拉（仅料号）；选后自动回填品名、单重、材质 |
| 品名规格 | 可搜索下拉（仅品名）；可由料号自动填入 |
| 单重（不含损耗）g | 可填克数或备注（如 **外购件**） |
| 材质 | 如 ADC12 |
| 客户交期 | 客户要求的交货日期 |
| 订单号 | 客户 PO 号 |
| PO 数量 | 本行订购数量 |
| 税率 (%) | 如 13 表示 13% |
| 人民币单价（含税） | 含税单价 |

> **系统自动填写（表单不显示）**：**接单日期** = 保存当天；新单 **已出货 0**、**单位 PCS**；账期可在 **订单明细 → 修改** 或客户档案中维护。

3. 填写完成后点击 **「提交录入」**。
4. 需要重新填写时，点 **「清空」** 可清空当前表单。

**防重复**：同一 **客户 + 订单号 + 品名规格** 只能有一条记录。若再次录入相同组合，系统会拒绝新建，并自动跳到 **订单明细** 高亮已有那一行，请用 **「修改」** 更新数量、日期等，不要重复提交。

**新录入提示**：成功新建后会自动打开 **订单明细**，对应行 **黄色高亮约 15 秒** 并滚动到可见位置；列表按 **最新录入** 排在最上。

**修改已有记录**

请到左侧 **「订单明细」**（或未结/结案列表）中操作：

1. 找到要改的那一行，点击 **「修改」**。
2. 该行变为可编辑状态，直接在表格里改字段；**未结数量** 会随 PO、已出货自动更新。
3. 点 **「保存」** 写入数据库；点 **「取消」** 放弃修改。

### 3.5 查看和管理已录入订单

在左侧进入 **「订单明细」**（或 **未结订单 / 结案订单**）查看对应列表。

**查找与筛选**

- 表头每列右侧有 **▾** 按钮，点击打开 **Excel 式下拉筛选**（勾选要显示的值）。
- 支持 **全选**、**搜索选项**、**确定** / **重置**；已筛选的列 ▾ 会 **高亮**。
- 可同时筛选多列（且条件）；点 **「清空筛选」** 清除当前子模块全部筛选。
- 切换 **订单明细 / 出货明细 / 未结 / 结案** 时，各子模块各自记住筛选，互不影响。
- 摘要行会显示「共 N 条，筛选后 M 条」。

**列表里有哪些信息**

每条记录一行，主要包含：客户、接单日期、客户交期、**录入时间**（系统在您保存时自动记录，不可手改）、订单号、品名规格、客户料号、单重、材质、PO 数量、已出货、未结数量、单位、税率、含税单价、账期等。

- **未结数量** 由系统自动计算（PO 数量 − 已出货），无需手工填写。
- 列表按 **最新录入** 排在最上（刚保存的行在最前）。
- 页面上会显示「共 N 条」表示当前有多少条记录。

**可执行的操作**

| 列表 | 操作 |
|------|------|
| 订单明细 / 结案 | **修改**、**删除** |
| 未结订单 | **出货**（见下节） |

---

### 3.5.1 未结订单 · 出货操作

1. 进入 **「未结订单」**，找到要发货的料号行。
2. 点 **「出货」**，输入 **本次出货数量**（不能超过当前未结数量）。
3. 系统把数量累加到 **已出货**，**未结 = PO − 已出货**（订单明细、结案列表同步更新）。
4. 若出货后未结为 **0**，该行从未结列表消失，出现在 **「结案订单」**。
5. **接单日期** 早于 6 个月的行会 **橙色高亮**，便于跟进老单。
6. 点 **出货** 后弹出 **送货单确认** 页：可核对/修改收货信息、明细（批号、箱数、备注等）、签收栏，确认后完成出货并自动打开送货单；也可在 **「出货明细」** 补打。

---

### 3.5.2 客商信息维护与送货单（可选）

顶部 **客商信息维护** ▾ → **客户信息维护**：维护客户档案；表头 **客户 ▾** 可筛选，底部 **清空筛选 / 刷新**。新增表单为 **两排** 录入（上排基本联系信息，下排账期/送货单等）。**送货单为可选项**，启用时可选择 **威可特统一模板**（全公司标准版式）或 **专用 Excel 模板**（`data/delivery_templates/files/` 下文件）。抬头为 **收货公司**（客户名称），供应商固定为 **昆山威可特精密电子有限公司**。

**供应商信息维护**：表头 **供应商 ▾** 可筛选；新增表单同为两排；底部 **清空筛选 / 条数 / 刷新**。

**维护步骤**

1. 进入 **客商信息维护 → 客户信息维护**。
2. 上方 **两排表单** 填写新客户信息并 **添加客户**。
3. 列表表头 **客户 ▾** 筛选；底部 **清空筛选** 恢复全部，**刷新** 重新加载。
2. **新增客户**：在上方表单填写客户名称、地址、联系人等；送货单选「不使用 / 威可特统一模板 / 专用模板」后点 **添加客户**。
3. **客户一览**：表格内编辑地址、联系人、电话、邮箱、账期、**对账周期**（自然月 / 21日～次月20日 / 26日～25日等）及送货单选项，点 **保存**。
4. 启用送货单的客户可点 **预览** 下载「已填入示例数据」的 Excel，核对占位符位置。

#### 专用 Excel 送货单（占位符自动填入）

1. 在 Excel 模板单元格写 **占位符**（英文双花括号），如 `{{客户}}`、`{{订单号}}`、`{{本次出货}}`、`{{收货地址}}` 等。
2. 客户信息维护 → **专用模板** → 上传 Excel → 保存。
3. **预览** 下载示例 Excel，确认每个占位符出现在正确位置。
4. **出货** 时系统自动替换为真实订单数据并在 Excel 中打开；核对后 Ctrl+S 保存，附件写入 **出货明细**。

**表格列（威可特统一模板出货时自动填入）**

订单号、客户物料编码、物料名称、规格型号、单位、数量、生产批号、箱数、备注。其中品名来自订单「品名规格」，规格型号来自「材质」；生产批号、箱数、备注暂留空，可后续扩展。

**出货时**

- 在 **未结订单** 点「出货」→ 弹出与正式送货单**相同版式**的确认页（已自动填入的可直接核对，浅黄底为待手填：收货地点、联系人、批号、箱数、签收等）→ **确认出货并生成送货单** 后自动打开打印页，可 **下载 Excel**。
- **出货明细** 每行可点 **「送货单」** 补打（内容与确认时一致）。

### 3.6 新增客户与料号（BOM）

**新增客户名称**

1. 进入 **客商信息维护 → 客户信息维护**，在上方表单填写新客户名称并 **添加客户**。
2. 补全地址、账期、对账周期等档案。

**新增客户料号（须在 BOM 录入）**

1. 顶部 **BOM信息 → BOM录入**，填写客户、产品料号、品名、单重、材质及工序（详见 **§四**）。
2. 保存后，订单录入时通过 **客户料号** 或 **品名规格** 搜索下拉选料即可自动带出主数据。

---

### 3.7 填写时注意什么

- **必填项**：客户、接单日期、订单号、品名规格、PO 数量。
- **客户料号**：若填写，须已在 **BOM录入** 建档且客户一致，否则提交会被拒绝。
- **PO 数量** 必须大于 0。
- **已出货** 不能小于 0，也不能大于 PO 数量。
- **单价、单重、税率** 不能为负数。
- **小数位（计算口径）**：数量最多 **1 位**、单重 **2 位**、单价 **4 位**、金额 **2 位**（均四舍五入）。
- **列表展示**：数量与金额带**千分位**；**整数不写小数**（如 `1,407,510`），有小数则显示（如 `2,996.9`、`352,300.56`）。
- **列筛选 · 客户**：在表头「客户」列点 ▾，勾选要看的客户即可。

> **数据保存**  
> 手工录入、Excel 导入、OCR 确认提交的订单，均写入本地数据库 **`P:\WKT\data\wkt_orders.db`**。重启网页服务后数据**仍会保留**。  
> 本地要与云端生产一致：运行 **`一键下载云端数据覆盖本地.bat`**（本地 `data/` 会先备份）。勿使用已删除的清库脚本。  
> 数据库文件请勿提交到 Git（已在 `.gitignore` 中排除）。

## 四、BOM 信息（料号主数据）

**BOM** 是系统中 **客户料号的主数据**：模具、单重、材质、工序与成本均在此维护。订单录入时填写客户料号，系统 **只查 BOM**，不会从已有订单反推料号。

### 4.1 BOM 录入

进入 **BOM信息 → BOM录入** 后，须 **先选择录入方式**（与订单录入相同）：**Excel 批量导入** 或 **手动录入**。未选择前只显示两个按钮和提示「请先选择录入方式」。

**方式 A：Excel 批量导入（推荐，历史 Excel）**

1. 选择 **Excel 批量导入**。
2. 选择威可特 **「新产品 BOM 表」** Excel（**每个 sheet 一个产品**；支持 `.xlsx` / `.xlsm` / `.xls`），点 **解析预览**。解析阶段 **只展示 Excel 全部行、不写库、不合并覆盖**；多 Sheet **共用表头**且品名写在一起（如 `SD-819/826/826A头壳`）、客户料号相同时，系统会 **按 Sheet 名** 拆成多条 BOM。  
   **文件名建议含客户简称**（如 `东硕BOM.xls`），系统会尝试匹配客商档案全称；表内或文件名识别不准时，可在预览表中 **直接改「客户」列**，或使用 **「统一客户」** 批量应用到全部 / 阻断·待核行，再点 **应用到全部** 或 **应用到阻断/待核**。
3. **核对预览表**（可编辑 Sheet、客户、料号、品名、单重等；说明列悬停可看全文）：  
   - 🟢 **通过** — 可直接导入  
   - 🟡 **待核** — 缺模具/单重等或工序模糊，可改表后导入  
   - 🔴 **阻断** — 缺料号/客户等，须先改表或统一客户后重新校验  
   - 🟠 **料号重复** — 本批多行相同料号会 **橙色高亮** 并标「料号重复」，请核对 Excel 是否填错；上传时 **以后者为准**
4. 确认无误后，点预览表 **底部「批量上传」**（非页面顶部按钮）。**上传时** 若库中已有同料号 BOM，会提示并将 **按产品料号覆盖**（以本次上传为准）；解析预览阶段不会出现覆盖提示。
5. **成功** 后会显示绿色提示，并可点 **「前往 BOM 查询」**；界面回到干净的上传页，可继续导入下一文件。  
   **同一料号**：重复上传或再次导入时，**按产品料号覆盖**，以 **最后一次导入为准**（无需勾选选项）。
6. **工序单价** 导入默认为 0；导入后在 **BOM 查询** 中补价。  
   外发供应商若尚未在 **供应商信息维护** 建档，导入时仍按 Excel 原文写入，建议事后补档案。

**方式 B：网页逐条录入（手动录入）**

1. 选择 **手动录入**。
2. 填写 **客户名称**、**产品料号**、品名、模具、单重、材质、机台吨位等；勾选 **工序** 并填写单价。
3. 外发工序可 **添加多家供应商**（标签展示，搜索框继续添加；× 可移除）；第一家为主供应商，用于默认展示与兼容旧数据。
4. 勾选工序后，**工艺顺序** 区用 **↑↓** 调整先后。
5. 输入料号后若已有 BOM，可自动带出部分字段；否则填完整后 **保存**。
6. 同一料号只能绑定 **一个客户**；与已有 BOM 客户不一致时系统拒绝保存。

### 4.2 BOM 查询

1. **「BOM信息」** → **「BOM查询」**（`/bom/query`）。
2. 可按客户、料号、品名等 **关键字查询**（客户支持 **模糊匹配**，简称如「大沃」可搜到全称档案）。
3. 列表按 **更新时间** 排序，刚导入或覆盖的记录排在 **最前**。
4. 表头各列（除「操作」）点 **▾** 可 **列筛选**；**「清空列筛选」** 清除列筛选。
5. 支持 **修改**、**删除**；修改时可调整 **工艺顺序** 及每道外发工序的 **多家供应商**。

### 4.3 与订单录入的关系

1. 在 **订单录入** 优先选/填 **客户料号**（可搜索下拉），系统自动回填品名、单重、材质；仅填品名时亦可搜索选择。
2. 若料号 **尚未在 BOM 录入**，保存订单时会提示：**请先在「BOM 录入」中维护该料号**。
3. 订单中的客户须与 BOM 绑定客户一致（支持简称，如「怡利」对应档案中的全称）。
4. 无客户料号的订单行（仅品名）仍可保存，但建议有料号的物料均先在 BOM 建档。

> **说明**：顶部 **「BOM信息」** 下的录入/查询即原「成本录入/成本查询」的升级命名；浏览器内 **客户报价试算** 页（`/cost`）仍保留，用于不存库的即时测算。

## 四附、库存（成品 / 半成品）

按 BOM 工艺路线记录各环节数量。料号须先在 **BOM录入** 建档。

### 库存总览（`/inventory`）

- **搜索**：可填 **产品料号**、**产品名称**、**客户名称**（均支持 BOM 下拉联想、互填）；留空则查全部有库存的料号。
- 卡片显示：**料号**、**品名**、右侧 **客户名称** 与各工序 **场内 / 在途**、**成品库存**。在途>0 标 **待回货**。
- 料号旁标注 **测**（演示/测试数据）或 **实**（正式数据）。
- 子模块切换请用顶栏 **库存 ▾** 菜单（总览 / 工序出入库 / 出入库流水）。
- 历史变动请到 **出入库流水** 子模块查询。

### 出入库流水（`/inventory/movements`）

- **搜索**：**产品料号** / **产品名称** / **客户名称**（均支持 BOM 下拉联想）；**日期** 可选（留空查最近记录，最多 500 条）。
- **今天**：快捷筛选当日全部料号流水。
- 列与 **当日出入库流水** 一致：**时间**、**客户名称**、**客户料号**、**产品名称**、动作、工序（路线，如 `01 压铸 → 13 CNC`）、数量、单号、备注、**操作**（可修改流水）。

### 工序库存（`/inventory/entry`）

按 **工艺环节** 维护各道库存，不在此做销售订单绑定。

1. 填写 **料号 / 品名 / 客户**（BOM 联想互填）→ **载入工序库存**。
2. 每道工序卡片固定显示 **场内库存 / 在途库存 / 返修** 及 **供应商**（成品为成品库存 / 返修在途）。
3. **点选工序**（最多 2 道，角标 ①②）→ 工具条 **编辑 / 清除**：
   - **选 1 道 → 编辑**：改本道各桶数量，**必选供应商**（默认 BOM，可改并回写 BOM）；保存记改数流水。
   - **选 2 道 → 编辑**：登记 ①→② **流转**（各选流出/流入状态、数量，**两道各选供应商**）；保存记流转流水。
4. 下方 **工序流动记录** 按已载入料号展示（未载入时显示当日流水）：
   - 改数流水：动作如 **修改在途库存**；工序列仅工序名（如 `02 去毛边`）；数量列为 **变动量**（差额）；备注列为供应商名。
   - 流转流水：工序列显示路线（如 `01 压铸 · 场内 → 02 去毛边 · 在途`）。

**单号（自动）**：全部记 **`WKT` + 日期 + 三位序号**（如 `WKT20260729001`）。

5. 查更长历史请到顶栏 **出入库流水**。
6. **改错**：
   - **修改流水**：可编辑的入库/出库/跳序/返修/流转流水，行末 **修改** 可改数量/备注（**改数流水**、订单出货流水不可改）。
   - **再次改数**：点选工序 → 编辑 → 保存，系统记新的改数流水。

跟催在途：总览或本页看工序卡片「在途库存」数量。

**订单出货扣库**：未结订单确认出货时仍自动扣成品仓；成品不足则无法出货。

## 四附2、对账（应收 / 应付）

顶栏 **对账 ▾** → **应收** 或 **应付**。

### 应收（`/#reconcile`）

打开即按 **收款月份** 自 **本月起重连续 6 个月** 滚动展示（列表区域内上下滚动）：

- 每月一段：各 **客户** + 到期金额 + 段内合计
- 点 **查看明细** 看该客户该月出货对账行

### 应付（`/#payable`）

同样 **自本月起重 6 个付款月** 滚动展示：

- 每月一段：各 **供应商** + 到期金额
- 点 **查看明细** 看该供应商该月回货行；可筛 **收货起止**

建议在 **供应商信息维护** 补全账期、对账周期。

## 五、飞书通知（可选）

订单、库存、BOM、客商档案等 **任意写操作** 及 **系统迭代部署** 可推送到飞书群。

**配置（由管理员完成一次即可）**

1. 在飞书群添加 **自定义机器人**，复制 **Webhook 地址**。
2. 编辑云端 `data/feishu_config.json`（本地调试同理），将 `enabled` 设为 `true`，填入 `webhook_url`。
3. 重启服务（本地：「一键启动网页.bat」；云端：同步后自动重启）。
4. 测试：`fetch("/api/feishu/test", {method:"POST"})`，飞书群应收到测试消息。

**推送范围**

| 类型 | 说明 |
|------|------|
| **操作通知** | 用户登录/退出；订单、出货、库存、BOM、客商、送货单、用户管理等写操作（含操作人、IP） |
| **系统更新** | 每次 **「一键推送云端和 GitHub」** 部署完成后，推送版本号、build、CHANGELOG 摘要 |

可按 `events` 中 `audit_action`（操作）、`system_deploy`（部署）等开关单独关闭。详见 `data/feishu_README.md`。

## 六、怎样关闭系统

关闭启动时弹出的那个命令行窗口，或在窗口里按 `Ctrl + C`，网页服务即停止。

下次使用时，重新双击「一键启动网页.bat」即可。

## 七、常见问题

| 遇到的情况 | 怎么处理 |
|------------|----------|
| 浏览器提示无法连接、页面打不开 | 检查启动系统的窗口是否还在运行；若已关闭，重新双击「一键启动网页.bat」 |
| 页面内容和之前不一样、像旧版 | 在浏览器里按 `Ctrl + F5` 强制刷新 |
| 提示缺少 RapidOCR | 在命令行执行：`pip install -r test_impl/web/requirements.txt` |
| 预览里有黄色格子 | 该字段未通过规则校验，请对照原订单或 OCR 原文确认 |
| 识别出来的字有错误 | 在「识别预览」表格里直接改，改完再批量提交 |
| 点了「手动录入」没反应 | 按 `Ctrl + F5` 刷新页面后重试 |
| 录入的数据不见了 | 演示环境下，关闭服务窗口后数据会清空，属于正常现象 |
| 想改已经提交的记录 | 打开「订单明细」，点「修改」→ 行内改完点「保存」 |
| 未结订单如何登记发货 | 在「未结订单」点「出货」，填写本次数量 |
| 出货后找不到该行 | 未结已为 0 时，请到「结案订单」查看 |
| BOM 批量上传后像没反应 | 成功后会显示 **绿色提示** 并回到上传页；点 **前往 BOM 查询** 确认；若无提示按 `Ctrl+F5` 刷新后重试 |
| BOM 导入成功但查询找不到 | 查询框试 **客户简称或全称**（支持模糊）；列表按 **更新时间** 排序，刚导入的在最前 |
| 同一 Excel 重复导入 | **按料号覆盖**，以最后一次为准；不会保留旧版同料号 |
| BOM 预览客户不对 / 阻断 | 在预览表改 **客户** 列，或用 **统一客户** 批量应用，再点底部 **批量上传** |
| 改了程序但页面像旧版 | 重启「一键启动网页.bat」，浏览器 `Ctrl+F5`；或访问 `/api/health` 看 `build` 是否为新版本 |
