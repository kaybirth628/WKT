### v0.6.0 主要内容

- **成本分析**：拆为成本录入 + 成本查询；记录持久化、编辑/删除；料号联想与单重回填
- **客商信息维护**：客户 + 供应商子模块；客户对账周期二选一
- **工艺选择**：36 项工艺编码；卡片对齐优化
- **导航**：成本分析、客商信息维护下拉子菜单；AI 助手暂隐藏

### v0.5.1 主要内容

- **顶部导航**：订单管理下拉；对账/送货单/成本/AI 顶栏入口
- **页脚说明**：模块标题与说明移至底部，内容区全宽
- **成本分析**：全宽双栏布局
- **治理**：`docs/RESTORE.md`；`docs/handoff/SESSION-20260530-ui-baseline.md`

### v0.5.0 主要内容（Git `e5f73b9`，左侧栏，已被 v0.5.1 取代）

- 恢复模块 + **左侧栏**导航

### v0.4.0 主要内容

- **SQLite 持久化**：重启后订单与出货记录保留
- **出货明细 / 未结出货**：部分数量出货、`shipment_events` 追溯
- **WKT 统一送货单**：HTML 打印 + xlsx；送货单维护页配置收货信息
- **出货确认弹窗**：出货前编辑送货单，快照入库
- **飞书 Webhook**：录入/修改/删除/出货/导入事件推送（可选）
- **OCR 原件高清预览**：PDF 200 DPI 渲染，上原件下识别表
- **治理**：`AGENTS.md` 会话连贯性协议

### v0.3.7 主要内容

- **设计库**：`docs/design/awesome-design-md/`（73 套大厂 DESIGN.md）
- **UI 主题**：Linear 深色（`#010102` 画布 + `#5e6ad2` 强调色 + Inter 字体）

### v0.3.6 主要内容

- **客户维护**：`/customers` 维护客户名称 + 标准账期
- **自动账期**：OCR/录入匹配客户后统一账期，覆盖英文等 OCR 原文

### v0.3.5 主要内容

- **单路 OCR**：PDF 文字层 / RapidOCR → DeepSeek → 规则校验（移除双方案，提速）
- **保留**：多文件一次上传、OCR 原文、黄标记校验

### v0.3.4 主要内容

- **OCR 上传**：一次可选多个 PDF/图片，顺序识别后合并预览、一次批量提交

### v0.3.3 主要内容

- **方案一**：PDF 文字层 / RapidOCR 本地（300 DPI）
- **方案二**：百度 OCR 高精度（云端，需联网 + 密钥）
- **对比**：双路 AI 结构化逐字段比对 + OCR 原文左右对照
- **填表**：以方案一为准 + 规则校验黄标记

### v0.3.0 主要内容

- **数据模型**：料号行平铺（模板2，15 列 RMB 口径，一料号一行）
- **手动录入**：紧凑 5 列网格表单，主数据下拉 +「+」快捷新增
- **录入方式**：先选 OCR / 手动，未选前不显示内容区；OCR 识别成功后才显示预览
- **列表**：已录入订单可搜索、修改、删除；悬停仅显示自定义 tooltip
- **UI 基线**：侧栏 + 卡片布局；详见 `docs/design/ui-style-guide-v1.md`
