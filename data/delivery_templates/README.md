# 送货单（威可特统一版式）

全公司使用同一送货单版式，与标准 Excel 样张一致。维护入口：**订单管理 → 送货单维护**。

## 配置文件

| 文件 | 说明 |
|------|------|
| `wkt_company.json` | 供应商（威可特）名称、地址、电话、底栏「一式四联」说明、默认单号前缀 |
| `customer_delivery.json` | 每客户收货地点、联系人、送货单号前缀（如 ABL） |

## 维护步骤

1. 在网页选择客户，填写 **收货地点**、**联系人及电话**、可选 **送货单号前缀**。
2. 点 **预览** 查看示例版式；出货成功后自动填入真实订单数据。
3. 打印页可 **下载 Excel**，版式与网页一致。

## 出货自动填入

- 抬头：收货公司 = 客户名（可在 `customer_delivery.json` 覆盖 `receiver_company`）
- 表格：订单号、客户料号、品名规格→物料名称、材质→规格型号、单位、本次出货数量
- 生产批号 / 箱数 / 备注：暂留空

## 遗留文件

`files/*.xlsx` 与 `mapping.json` 为旧版按客户 Excel 模板机制，当前出货已不再使用；可保留作备份。
