# 送货单（威可特统一 + 客户专用）

## 默认：威可特统一模板

除下列 4 家外，所有客户出货时使用 **威可特统一送货单**（`wkt_standard`），网页预览 + Excel 下载版式一致。

维护：**订单管理 → 送货单维护**（收货地址、联系人、单号前缀）。

### 制作 / 替换专用模板

1. 用 Excel 按客户要求做好版式。
2. 在单元格中使用占位符，出货时自动替换，例如：`{{客户}}` `{{订单号}}` `{{品名规格}}` `{{客户料号}}` `{{本次出货}}` `{{出货日期}}` `{{材质}}` `{{单位}}` 等。
3. 保存为 `.xlsx`，文件名与上表一致，放入 `files/` 覆盖占位文件。

生成占位模板（首次或重置）：

```powershell
python scripts/init_special_delivery_templates.py
```

生成**双语专用版式**（浙江金棒、上海金脉，对齐客户 Excel 样张）：

```powershell
python scripts/build_bilingual_delivery_templates.py
```

占位符除 `{{客户}}` `{{订单号}}` `{{本次出货}}` 等外，双语模板还支持 `{{送货单号}}` `{{制单日期}}` `{{发货日期}}` `{{供应商名称}}` `{{收货地址}}` `{{收货联系人}}` `{{收货电话}}` 等（出货时自动填入）。
