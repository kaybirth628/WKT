# 送货单（威可特统一 + 客户专用 Excel）

## 威可特统一模板（默认）

未配置专用模板的客户，出货时使用 **威可特统一送货单**（网页确认 + 打印 / Excel 下载）。

维护：**客户信息维护** → 送货单选「威可特统一模板」。

## 专用 Excel 模板（占位符自动填入）

### 1. 制作模板

在 Excel 单元格中写入占位符（英文双花括号），例如：

| 占位符 | 填入内容 |
|--------|----------|
| `{{客户}}` | 客户名称 |
| `{{订单号}}` | PO 号 |
| `{{品名规格}}` | 品名 |
| `{{客户料号}}` | 客户料号 |
| `{{材质}}` | 材质 |
| `{{本次出货}}` | 本次出货数量 |
| `{{出货日期}}` | 出货日期 |
| `{{收货地址}}` | 客户档案地址 |
| `{{送货地点}}` | 同收货地址（部分客户模板用语） |
| `{{订单下发抬头}}` | 客户收货公司 / 订单抬头 |
| `{{收货联系人}}` | 联系人 |
| `{{收货电话}}` | 电话 |
| `{{送货单号}}` | 系统生成的单号 |
| `{{供应商名称}}` | 威可特公司名 |

合并出货时：明细行占位符（如 `{{订单号}}`、`{{客户料号}}`、`{{本次出货}}`）会按料号自动扩展为多行；`{{合计}}` 为总数量。

### 2. 上传与预览

1. **客户信息维护** → 专用模板 → 上传 `.xlsx` → 保存。
2. 点 **预览** → 下载「已填入示例数据」的 Excel，确认占位符位置正确。

### 3. 出货

确认出货后，系统 **自动替换占位符** 并在本机 **Excel 打开**；核对后 Ctrl+S 保存，附件写入 **出货明细**。

## 文件位置

| 路径 | 说明 |
|------|------|
| `data/delivery_templates/files/*.xlsx` | 各客户模板（含占位符） |
| `data/delivery_templates/mapping.json` | 客户 → 模板文件名 |
| `data/delivery_notes/attachments/` | 出货后保存的送货单附件 |
