# 本地数据看板（自动生成，勿手改 index.html）

运行生成：

```powershell
python scripts/generate_data_dashboard.py
```

然后在浏览器打开 **`data/dashboard/index.html`**。

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 树杈思维导图看板（自包含，可离线打开） |
| `dashboard.json` | 看板树结构数据 |
| `report.json` | 原始汇总数据（供 diff / 二次处理） |

## 看板结构

1. **数据总览** — 根节点 → 基础资料 / 销售·订单出货 / JSON 配置 → 各表与文件（曲线连接）
2. **缺口与不一致** — 按类型树杈展示，每条叶子含原因摘要
3. **不一致明细表** — 对象、具体原因、影响、建议（需处理 / 提示）
4. **按客户牵连** — 每个客户一张小树杈

底部图例说明表与表之间的关联键名。

数据变更后重新运行生成脚本即可更新看板。
